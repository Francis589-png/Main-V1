# Main V1

A modern, privacy-conscious communication platform.

## V1 goals

- Firebase Authentication for accounts
- Firebase Realtime Database for realtime chat state
- Media stored separately from realtime data
- Professional, mobile-first UI/UX
- Architecture ready to grow into communities, businesses, jobs, and professional networking

## Product principles

1. Fast and simple
2. Clear navigation
3. Mobile-first
4. Realtime where realtime matters
5. Minimize unnecessary backend usage
6. Build the foundation before adding complexity
