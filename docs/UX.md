## UX states

Every network-backed screen must have intentional states for:

- Loading
- Empty
- Offline
- Error
- Retry
- Success

## Design direction

Main should feel modern, calm, premium, and fast. It should not visually imitate WhatsApp. Use a restrained visual language, consistent spacing, accessible typography, subtle motion, and both light and dark themes.

## V2 compatibility

The V1 information architecture must leave room for:

- Businesses
- Jobs
- Professional profiles
- Posts
- Networking
- Marketplace
